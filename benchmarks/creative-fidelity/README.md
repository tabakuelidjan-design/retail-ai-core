# Creative Fidelity benchmark data

This directory contains only benchmark structure and documentation.

Do not commit merchant product originals, customer photos, faces, API keys, generated private assets, or sensitive HABB data here.

A local/private manifest should conform to `manifest.schema.json` and use opaque source references. Pilot assets remain outside generic architecture and must respect NDR-020.

Initial target: 10 difficult real HABB products, each exercised across the same five benchmark tasks.
