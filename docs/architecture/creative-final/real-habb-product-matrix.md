## Findings that matter beyond the table
1. **Four of the nine assets are pre-cut PNGs with native alpha (253 inside).** The pipeline has no *native-alpha path* (trust the alpha, run alpha-appropriate checks). Flattening them on white and re-segmenting throws information away, and the photograph-oriented reconstruction checks do not suit a pre-cut matte. This is a NOT_IMPLEMENTED capability, not a threshold problem.
2. **Baked glows and shadows in supplier renders are fatal for any matte** — the source must be cleaned or a better asset used. The fix is upstream (asset hygiene), not a looser gate.
3. **The one real HABB photograph (benchmark-001) is outside the local segmenter's domain**; the older annotated-outline segmenter was built for it.
4. The shoot list **A9** in `BENCHMARK_RUNBOOK.md` (gift box, UV item, hand holding a case, touching products, on a plain mid-grey ground) is what would turn this matrix from "supplier renders" into a measurement of HABB's real use.
