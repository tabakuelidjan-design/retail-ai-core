# Nordla Creative vs a strong general assistant's creative abilities — gap matrix (2026-10-14)

"ChatGPT-like target" is a behavioural target, not a product claim. **No equivalence is claimed or proven anywhere in this document.** Status words: DONE (works, tested), PARTIAL, INTERFACE_ONLY, NONE. "Tested" means tests on drawn fixtures or fake ports unless a real run is stated.

| Capability | Target behaviour | Current Nordla status | Gap | Priority | Blocker | Recommended next step |
|---|---|---|---|---|---|---|
| Multimodal understanding | read a brief, a document, a photo, a screenshot and know what is in it | **NONE** end to end: `understandInputs` exists with a port, but no real understand port is connected; the Brain takes a prepared brief | no ingestion of a raw image/doc/URL | HIGH (everything starts here) | provider choice (vision-language model) | connect a vision-language port behind `ports[kind].understand`, benchmark on HABB briefs |
| Image-conditioned creation | "make something like this, with my product" | **PARTIAL**: real product pixels are cut out and composed with generated plates/props; the single-image path uses Qwen product edit | no real layer generator in the layered path; no reference-style conditioning | HIGH | no plate/prop provider connected | benchmark + connect one plate/prop generator |
| Iterative visual editing ("make the shadow softer", "move it left") | conversational edits on the last result | **PARTIAL**: REFINE repairs a layer (reposition/remove/regenerate prop or plate/typography) from structured defects; critique → action mapping exists | no natural-language → defect parser in a loop; refine has no caller | MEDIUM | no entry point / conversation layer | after the entry point exists, map operator text to `defectsFromRevisionIntents` |
| Masked editing | edit exactly this region, nothing else | **INTERFACE_ONLY**: request, validation, protected-pixel output check; `PROVIDER_NOT_CONNECTED` | no provider, no executable scope | HIGH for local fixes | provider benchmark | runbook §2.2 |
| Object-preserving edits | change the scene, never the product | **DONE (by construction)**: the product is never regenerated; identity gate + compositor pixel check; bounded relight/grade; shadow as a separate layer | only for scenes composed by Nordla; a provider edit of a full image is NOT identity-safe | HIGH (core promise) | — | keep the rule: provider output never replaces product pixels |
| Scene composition | place the product in a believable scene | **PARTIAL**: layered scene spec, deterministic compositor, placement rules, contact shadow, bounded grade — all on drawn fixtures and 1 real case | no real plates; integration not wired into the layered runtime; shadows are an approximation (no light estimation) | HIGH | plate provider; wiring | wire `integrateProduct` into the layered runtime, then run the benchmark |
| Long-form creative planning | turn a long text into a plan of assets | **DONE (tested with fakes)**: content format planner, long-copy decomposition, campaign planner, copy distribution | never run on real HABB long copy with a real model | MEDIUM | real run | one supervised real campaign run after wiring |
| Multi-asset generation | a coherent set (carousel, campaign) | **PARTIAL**: carousel/campaign planning + continuity/diversity rules + budget; production of each asset not chained | no orchestrator calling production per asset | MEDIUM | entry point | orchestrator after the entry point |
| Visual reasoning (spatial, light, perspective) | understand why a render looks wrong | **PARTIAL**: deterministic geometry/light checks (placement, shadow direction, contact, halo); the critic is a model port run outside the layered path | no model-level spatial reasoning in the loop | MEDIUM | critic not wired to layered gates | wire the critic as a gate after the deterministic ones |
| Self-critique | judge its own output and improve | **PARTIAL**: C3 critic (real Qwen vision, run by scripts), revision director, REFINE planner | not an automatic loop; no real run recorded in the layered path | MEDIUM | wiring | closed loop with attempt caps after wiring |
| Recovery after a failed render | notice, explain, retry smartly | **DONE for the deterministic stack**: every stop is classified (block codes, nine integration states), REFINE ladder (reposition → remove → replan), attempt cap 3; **NONE for provider failures** (no real provider in the loop) | provider timeout/refusal/NSFW-filter handling untested | MEDIUM | providers | handle in the provider adapters |
| Contextual memory | remember brand, previous assets, decisions | **PARTIAL**: working memory of repairs (plain JSON), layer store, ledger; brand tokens through the branding module | no cross-session creative memory of what the owner liked | LOW now | product decision | after launch |
| Provider / tool orchestration | pick the right tool, respect cost | **PARTIAL**: capability router, provider gate (`OPEN` only on explicit approval), budget reservation, no silent tool switch | gate defaults, no real tools, nothing exercised live | HIGH | providers | benchmark → wire → live smoke under a ceiling |
| Real product preservation | the product in the output is the product | **DONE as a design and tested on drawn fixtures + 1 real photo**; 5 of 6 real HABB assets tried fail closed (see real-product matrix) | native-alpha / pre-cut assets, reflective edges, ground-colour products need other paths | HIGH | segmentation provider and a native-alpha path | runbook §2.1 and a native-alpha path |

Overall: Nordla Creative is a **safer, more controllable but narrower and not yet connected** system than a general assistant. Its strengths are determinism, identity preservation and explicit failure; its weaknesses are no ingestion, no real generators in the layered path, no conversation layer and no entry point.
