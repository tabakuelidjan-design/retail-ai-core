# Creative provider gap matrix (2026-10-14)

Source: static reading of the worktree at `f9c8afd` plus the Creative docs. "Real provider connected" means: a non-fake implementation exists in `src/` AND is reachable from the Creative pipeline it belongs to. Candidates are categories to benchmark, **not recommendations**; none was chosen from marketing claims (see `BENCHMARK_RUNBOOK.md`).

Key facts behind the table
* The **layered runtime has no real layer generator**: all its tests use a fake layer port. Any real plate/prop requires writing the adapter between the layered request shape and a provider.
* The Phase 5 module is **not called by the layered runtime** (`integrateProduct` has no caller outside tests, one matrix script and the readiness gate).
* Real Qwen ports exist and have run in scripts (brain, director, vision critic, environment, product edit); none is reachable from a service or route.
