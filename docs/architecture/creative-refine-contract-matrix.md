# Creative refine contract matrix

Generated by `auditRefineParity()` from the real planner and masked-edit validators. Do not edit by hand. The refine has no model stage: every rule is proved by a probe that breaks it and checks that the planner refuses with the code of that rule.

## Probes

| rule | probe | holds |
|---|---|---|
| SAMPLE_IS_REPAIRABLE | A valid sample artifact has a legal, planned repair | yes |
| THE_REAL_PRODUCT_IS_NEVER_REPAIRED | A change to the real product pixels is refused | yes |
| LOCKED_COPY_IS_NEVER_CHANGED | A change to locked copy is refused | yes |
| NO_SCOPE_REGENERATES_THE_CREATIVE | No scope regenerates the whole creative, and a plan that regenerates every generated layer is refused | yes |
| UPSTREAM_AND_PROTECTED_NODES_ARE_NEVER_INVALIDATED | A layer repair never invalidates the upstream reasoning, the product or the locked text | yes |
| AN_UPSTREAM_DEFECT_IS_A_REPLAN | A defect that originates upstream is a replan request, answered by no layer repair | yes |
| THE_SCOPE_IS_DECLARED | A scope that does not exist, or is not allowed, is refused | yes |
| THE_OWNER_OF_A_DEFECT_IS_NEVER_GUESSED | The owner of a defect is never guessed: an unknown layer, or no name among several props | yes |
| A_REPAIR_ESCALATES_INSTEAD_OF_LOOPING | A placement defect escalates (reposition, reposition, remove) and then stops, instead of looping | yes |
| A_FAILED_REPAIR_IS_NOT_REPEATED | The same failed repair of the same artifact is not repeated | yes |
| THE_REPAIR_IS_COSTED_ON_THE_REPAIRED_WORK_ONLY | A repair is priced on the repaired layer only, and a deterministic repair costs nothing | yes |
| A_STALE_OR_INVALID_ARTIFACT_IS_REFUSED | A stale, invalid or empty request is refused | yes |
| A_MASKED_EDIT_IS_NEVER_FAKED | The masked-edit capability exists but says that no provider is connected, and a repair that needs it is refused | yes |
| A_MASK_NEVER_TOUCHES_A_PROTECTED_REGION | A mask that touches a protected region is refused before any provider is asked | yes |

## REFINE_PLANNER

No model answer: the smallest valid repair is derived from the defects, the layer dependency map and the working memory; no model is asked

## REFINE_EXECUTOR

No model answer: the repair re-runs the layered runtime on a copy of the shared layers and is checked node by node against its own plan

## MASKED_EDIT_CAPABILITY

No model answer: an interface with a request contract and checks; no provider is connected and nothing is simulated

PARITY: every refine rule is enforced by a planner that refuses with its code, and every probe holds.
