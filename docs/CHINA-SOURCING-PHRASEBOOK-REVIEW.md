# China Sourcing - Chinese phrasebook for native review

Generated by `node tools/phrasebook-review.mjs`. **No sentence below is certified.** A sentence becomes NATIVE_REVIEWED only when a native speaker has checked it and an entry is added to `NATIVE_REVIEW` in `src/sourcing/core/phrases.js` (reviewer, date). Until then the app shows its state next to the Chinese text ("non relue" / "relecture par un locuteur natif à faire") and never calls it a certified translation. **Critical sentences must be validated before real commercial use.**

How to review: for each row read the Chinese, compare with the French/English meaning, and answer OK / FIX (with the corrected sentence). Check especially: trade terms (MOQ 起订量, Incoterms, 定金/尾款), politeness level for a first meeting, and that model numbers / standards are inserted unchanged. Placeholders in braces are replaced by the case's own values, copied verbatim.
